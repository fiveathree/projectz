## 1. Tiled 編輯器

**而家點做**：`src/world/prefabs/*.txt` 有 10 款 22×18 嘅 ASCII 街區（北汐 7 款、汐景邨 3 款），由 `mapgen.ts` 洗牌、鏡像，再砌成地圖。

**轉用 Tiled 嘅好處**
- 可以畫唔規則嘅形狀，例如斜街、唔同大細嘅建築。
- 每格可以加額外屬性，例如指定物資、事件觸發點。
- Phaser 本身已經讀到 Tiled 嘅 JSON 格式（`this.make.tilemap({ key })`），符合原則 ⑤「用現成套件」。

**轉用 Tiled 嘅代價**
- 要額外裝同學識一個編輯器，DESIGN.md 原本揀 ASCII，就係為咗避免呢樣。
- JSON 檔好大，git diff 睇唔明，Claude 好難精準咁改。
- 而家嘅生成器有隨機組合同鏡像，轉用 Tiled 之後，要用佢嘅 object layer 重新做一次。

**幾時先值得轉**：要整一個大型、手工設計、唔重複嘅地標區（例如碼頭工業區成個區一次過畫）。到時就兩樣並存：Tiled 畫地標，ASCII 繼續做住宅街區。

## 2. 等距視角（45°）

**要改嘅地方**
- 渲染：Phaser 支援等距 tilemap，但牆嘅遮擋要按深度排序，牆仲要識變透明（例如入屋時屋頂同前牆淡出）。
- 視野：而家嘅格仔 DDA Raycast 同牆角射線係正方格假設，要改成喺斜軸上面計，再投影返去畫面。
- 碰撞同移動：WASD 要對應斜向，Arcade 物理仍然用平面座標，但同畫面之間要轉換。
- 美術：全部 Tile 同角色要重畫成等距版本，牆要有高度，數量至少多一倍。

**估計工作量**：大約係 Phase 0 到 2 嘅視野加美術部分嘅 3 倍。DESIGN.md §0 已經判斷過「俯視一樣有張力」。

**建議**：唔做。真係想加深度感，可以試平價方案：牆加 2–3px 嘅「頂部高光」同陰影偏移（Phase 2 嘅磚牆已經有頂部高光），或者入屋時令外牆淡出。

## 3. 多人連線

**最細可行版本（2–4 人合作）要有**
- 一個權威伺服器：Cloudflare Durable Object，每個世界一個實例，用 WebSocket 連接，負責喪屍 AI、流場、容器、存檔。
- 客戶端只送輸入，伺服器每秒送 10–20 次狀態快照，客戶端做插值；玩家自己嘅角色先做預測移動。
- 而家嘅 `GameState` 係單機物件（所有系統直接改佢），要拆做伺服器端模擬加客戶端渲染。`systems/*.ts` 大部分係純 TypeScript，可以搬去 Worker 行；`WorldScene` 就要拆開。
- 帳戶、房間、斷線重連、防作弊都要做；Durable Objects 同 WebSocket 會有持續費用（雖然細）。

**估計工作量**：等於成個 Phase 1 加 Phase 2 再做多一次，而且要持續營運。

**建議**：唔做。DESIGN.md §0 已經講明「唔做多人連線」；而家單人模式加盟友倖存者，已經有部分合作嘅感覺。如果將來真係要做，先做「同一世界、輪流玩」嘅非同步分享（上傳存檔，畀朋友喺你個世界撞到你嘅屍體），呢個用 Workers + R2 就做到，簡單好多。
